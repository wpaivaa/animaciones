Instrucciones para Proyectos de Videojuegos Web

Dr. Walter Richard Paiva Ayala. Estructura Técnica, 52 Ideas de la Región Piura.

Cada alumno seleccionará un idea de videojuego de los 52 propuestos y lo subirá en la plataforma virtual.

Propósito del Manual: Este documento ha sido diseñado como una guía metodológica y técnica completa para estudiantes y desarrolladores web. Presenta las bases arquitectónicas de integración entre el Frontend interactivo (HTML5, Canvas, CSS3, JavaScript) y el Backend transaccional (MySQL) a través de un catálogo de 52 ideas lúdicas de dos niveles fundamentadas rigurosamente en la cultura, geografía, folclor y dinámicas sociales de la Región Piura.

1. Arquitectura del Sistema e Infraestructura Técnica

Cada videojuego propuesto debe responder de forma estricta a un modelo de comunicación cliente-servidor desacoplado. A continuación se detallan las responsabilidades de cada capa tecnológica:

  • Capa de Presentación e Interacción (Frontend): Desarrollada en un único flujo web que renderiza un lienzo de dibujo dinámico mediante la API <canvas> de HTML5. JavaScript gestiona el bucle principal del juego (Game Loop), la actualización de coordenadas físicas, los eventos del teclado/ratón, la detección analítica de colisiones y la bifurcación lógica entre el Nivel 1 y el Nivel 2.
  • Capa de Persistencia y Datos (Backend + MySQL): Al completarse el segundo nivel de juego, se ejecuta una petición asíncrona estructurada (fetch() o XMLHttpRequest) en formato JSON, transfiriendo los metadatos de la sesión al servidor. Un script intermedio (por ejemplo, en PHP o Node.js) valida los datos y ejecuta sentencias preparadas hacia el motor relacional MySQL.

Diseño del Esquema de Base de Datos Relacional

Para asegurar la escalabilidad de cualquiera de los 52 videojuegos, se debe instanciar la siguiente estructura de tabla unificada para la gestión de récords y analíticas de sesión de usuario:

CREATE DATABASE IF NOT EXISTS juego_piurano_db;
USE juego_piurano_db;

CREATE TABLE IF NOT EXISTS tabla_records (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nombre_jugador VARCHAR(50) NOT NULL,
    puntaje_total INT NOT NULL,
    tiempo_segundos INT NOT NULL,
    nivel_alcanzado INT DEFAULT 2,
    fecha_registro TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

2. Catálogo de 52 Ideas de Videojuegos de Dos Niveles (Identidad Piurana)

El siguiente compendio presenta las mecánicas y el alcance secuencial para los dos niveles reglamentarios de cada propuesta lúdica:

1. El Dilema del Voto Ciudadano (Simulador de Elecciones Regionales) Nuevo
Nivel 1: El jugador recorre una plaza piurana recolectando folletos con propuestas reales de dos candidatos opuestos, clasificándolos y detectando noticias falsas en un límite de tiempo.
Nivel 2: Simulación interactiva del acto de votación en Canvas. El jugador ingresa a la cámara secreta, marca la cédula con precisión física e introduce el voto en el ánfora; el juego registra y procesa el voto final en la base de datos MySQL para actualizar un escrutinio global en tiempo real.
2. El Guardián del Éxodo Peatonal (Cruce Seguro en la Autopista) Nuevo
Nivel 1: Controlando a un brigadista en la avenida Sánchez Cerro, el jugador debe tomar de la mano a ancianos que avanzan lento y ayudarlos a cruzar el Canvas de extremo a extremo, esquivando automóviles y mototaxis cuyos vectores de velocidad varían.
Nivel 2: El desafío se traslada a una autopista interprovincial de alta velocidad en la salida a Sullana, asistiendo a niños en edad escolar. Se incorporan dinámicas de clima (viento y polvo) y semáforos manuales sincronizados que alteran el comportamiento del tráfico vehicular.
3. El Maestro Cevichero de Máncora
Nivel 1: Cortar el pescado en cubos simétricos cayendo en cascada en la pantalla, esquivando las espinas.
Nivel 2: Exprimir limones de Chulucanas evitando las pepas ácidas y verter el ají limo en la proporción exacta indicada por la barra indicadora.
4. El Secreto de la Causa Piurana
Nivel 1: Prensar la papa amarilla mediante pulsaciones rítmicas de teclas para conseguir una textura homogénea.
Nivel 2: Emplatar capturando ingredientes suspendidos (huevo, aceituna verde, escabeche) en el orden lineal correcto.
5. Herencia del Seco de Chabelo
Nivel 1: Machacar el plátano verde frito en un batán virtual mediante clics de alta precisión antes de que se enfríe.
Nivel 2: Sofreír la carne aliñada regulando un termostato digital para evitar la carbonización por leña de algarrobo.
6. El Punto del Clarito y la Chicha de Jora
Nivel 1: Desgranar maíz blanco del Bajo Piura arrastrando el cursor sobre un rodillo dentado en movimiento.
Nivel 2: Controlar la tasa de fermentación en tinajas de barro añadiendo agua o chancaca según los gases simulados en la interfaz.
7. Tamales de la Abuela Catacaos
Nivel 1: Moler el maíz tierno esquivando impurezas y piedras de río que caen por la tolva del molino manual.
Nivel 2: Envolver la masa homogénea en hojas de plátano trazando patrones geométricos con el ratón.
8. Copús Bajo la Tierra
Nivel 1: Cavar un pozo térmico uniforme y recolectar las piedras calientes correctas descartando tierra húmeda.
Nivel 2: Organizar capas de pavo, cabrito y camotes, sellando el horno herméticamente antes de que disminuya la temperatura crítica.
9. El Horneado del Pavo de Fiesta
Nivel 1: Marinar la pieza entera atrapando condimentos tradicionales en caída libre (chicha de jora, ají panca, comino).
Nivel 2: Monitorear la cocción en un horno de barro artesanal impidiendo que las corrientes de aire apaguen las brasas.
10. Natillas de San Clemente
Nivel 1: Ordeñar cabras en un entorno interactivo basado en barras de ritmo y sincronización de comandos.
Nivel 2: Batir la mezcla de leche y chancaca en pailas de bronce moviendo circularmente el cursor para prevenir adherencias.
11. La Picantería Tradicional
Nivel 1: Servir "tote" (cancha) y vasos de clarito a mesas de clientes demandantes bajo un esquema de gestión de colas.
Nivel 2: Izar y defender la bandera blanca o roja en la fachada exterior sorteando las ráfagas intensas de viento norteño.
12. Dulce de Guayaba de la Sierra
Nivel 1: Plataformas 2D donde se recolectan guayabas maduras trepando por las estribaciones arbóreas de Ayabaca.
Nivel 2: Hervir la pulpa controlando la densidad del almíbar esquivando proyecciones de burbujas calientes en el Canvas.
13. Siembra de Arroz en Terreno Suave
Nivel 1: Canalizar los flujos de agua desde la acequia principal abriendo compuertas lógicas para inundar el fango de manera milimétrica.
Nivel 2: Insertar bálagos de arroz a intervalos equidistantes utilizando un temporizador cíclico de inserción.
14. Siembra de Arroz en Terreno Duro
Nivel 1: Guiar una yunta de bueyes labrando surcos paralelos en tierra seca, esquivando peñascos subterráneos.
Nivel 2: Fragmentar bloques densos de arcilla con impactos consecutivos del mouse para preparar la cama de siembra.
15. El Oro Blanco: Algodón Pima
Nivel 1: Extraer copos limpios de algodón de las plantas evitando ramas secas y espinas punzantes.
Nivel 2: Apisonar el algodón recolectado dentro de sacos de yute industriales mediante saltos coordinados en pantalla.
16. Pastor de Cabras en el Desierto de Sechura
Nivel 1: Agrupar y conducir un hato de cabras hacia un bosque de algarrobos eludiendo ataques del zorro costeño.
Nivel 2: Recoger las vainas de algarroba maduras esparcidas por el suelo arenoso para mantener estables los niveles de energía de las crías.
17. Cosechador de Limón de Tambogrande
Nivel 1: Operar una pinza mecánica virtual para cortar mangos y limones óptimos descartando frutos con plagas.
Nivel 2: Clasificar la producción por calibres de exportación en fajas transportadoras de velocidad incremental.
18. El Mango de Exportación de San Lorenzo
Nivel 1: Desprender mangos de la variedad Kent con una vara de recolección larga ("gandul") impidiendo impactos directos contra el suelo.
Nivel 2: Sumergir la fruta en tanques térmicos automatizados para el tratamiento hidrotérmico reglamentario.
19. Cacao Blanco de Huancabamba
Nivel 1: Seccionar mazorcas de cacao criollo maduras usando cortes angulares precisos con un machete virtual.
Nivel 2: Desgranar las semillas almibaradas y disponerlas sobre camas de fermentación volteándolas a intervalos fijos.
20. El Guardián de la Acequia
Nivel 1: Retirar sedimentos e impurezas antropogénicas de los canales del Río Piura antes del arribo de la cresta de avenida.
Nivel 2: Distribuir cuotas hídricas volumétricas ("mitas") entre parcelas colindantes respetando un reloj de asignación justa.
21. La Cosecha del Banano Orgánico de Sullana
Nivel 1: Cortar racimos pendulares masivos y transportarlos balanceadamente sobre hombros digitales evitando caídas fatales.
Nivel 2: Colocar separadores plásticos de amortiguación en contenedores móviles para neutralizar el roce del transporte.
22. Apicultura en el Bosque Seco
Nivel 1: Mitigar la agresividad de las abejas aplicando ráfagas dosificadas de humo sobre panales silvestres de algarrobo.
Nivel 2: Controlar una centrífuga de extracción controlando las revoluciones por minuto para no destruir las estructuras de cera.
23. Pesca Artesanal en Cabo Blanco
Nivel 1: Lanzar líneas de nylon desde peñascos rocosos sorteando el oleaje violento y la interferencia de mantarrayas.
Nivel 2: Batallar en tensión física contra un espécimen de mero o merlín mediante la pulsación intermitente de la barra espaciadora.
24. El Viaje de los Balsares de Paita
Nivel 1: Ensamblar cordajes estructurales entrelazando haces densos de totora nativa para formar una embarcación flotante.
Nivel 2: Pilotar el balsa mar adentro esquivando corrientes de resaca y rompientes costeras críticas.
25. Recolector de Conchas Negras en los Manglares
Nivel 1: Introducir el brazo virtual en cavidades profundas del fango esquivando ataques directos de cangrejos violinistas.
Nivel 2: Evaluar las conchas con un calibrador óptico; reintegrar al ecosistema aquellas menores a la talla mínima legal.
26. Las Salinas de Sechura
Nivel 1: Distribuir agua de mar hiper-salina en pozas someras arrastrando palas articuladas mecánicamente con el ratón.
Nivel 2: Erigir montículos cónicos de sal cristalizada antes de la irrupción del viento racheado del desierto.
27. Torneo de Surf en Máncora
Nivel 1: Nivelar el centro de gravedad de una tabla dinámica mediante vectores direccionales sobre una ola oscilante en Canvas.
Nivel 2: Ejecutar maniobras aéreas calculando ángulos trigonométricos parabólicos para reingresar limpiamente a la pared de agua.
28. El Filigranista de Catacaos
Nivel 1: Trefilar metal precioso fundido estirándolo a través de hileras calibradas mediante un medidor de tensión interactivo.
Nivel 2: Interconectar filamentos microscópicos de plata sobre un molde base imitando la silueta de un pavo real clásico.
29. Alfarero de Chulucanas
Nivel 1: Modelar siluetas ovoides de arcilla en un torno rotatorio acoplando la velocidad angular al ritmo del teclado.
Nivel 2: Aplicar reservas de barbotina líquida para aislar zonas de color antes del proceso de horneado reductor.
30. El Secreto del Ahumado
Nivel 1: Abastecer el horno de Chulucanas con hojas seleccionadas de mango verde para generar el humo rico en carbono.
Nivel 2: Regular las compuertas de aireación para obtener la pátina negra brillante característica sobre la cerámica pulida.
31. Tejedora de Sombreros de Paja Toquilla
Nivel 1: Procesar químicamente los cogollos de paja mediante ebullición controlada y posterior azufrado de blanqueamiento.
Nivel 2: Ejecutar patrones de tejido concéntrico alternando cruzamientos rápidos bajo un formato de memoria visual de secuencias.
32. El Constructor de Botes de Astillero
Nivel 1: Calafatear juntas estructurales de madera insertando estopa impregnada en brea hirviente con herramientas virtuales.
Nivel 2: Rotular heráldica marina en la proa y deslizar la nave terminada sobre polines de madera hacia el plano del mar.
33. El Médico Curandero de Las Huaringas
Nivel 1: Ascender laderas verticales andinas recolectando plantas sagradas bajo condiciones de visibilidad nocturna reducida.
Nivel 2: Disponer la "mesada" ceremonial arrojando líquidos protectores ("floreos") y neutralizando entidades hostiles abstractas.
34. El Encanto de la Laguna de Ramón
Nivel 1: Maniobrar una balsa de troncos eludiendo fuegos fatuos luminiscentes y vórtices hidráulicos repentinos.
Nivel 2: Bucear para rescatar reliquias de oro precolombino antes de que se agote la reserva de oxígeno del buzo.
35. El Carretón de la Otra Vida
Nivel 1: Juego de carrera sin fin conduciendo un carruaje espectral por los arenales periféricos de la Piura antigua.
Nivel 2: Absorber fuegos fatuos de almas en pena antes del amanecer esquivando estructuras religiosas que restan energía.
36. La Fiesta de los Reyes Magos de Narihualá
Nivel 1: Trazar una trayectoria desértica guiando una caravana mediante la triangulación visual de un astro guía.
Nivel 2: Recitar coplas populares emparejando fragmentos poéticos correctos en un juego tipográfico contrarreloj.
37. Procesión del Señor de la Buena Muerte de Chocán
Nivel 1: Distribuir físicamente a los miembros de la hermandad según su estatura para estabilizar el centro de masa del anda.
Nivel 2: Avanzar por calles alfombradas con aserrín de colores ejecutando giros precisos para evadir cables y aleros coloniales.
38. El Ritmo del Tondero
Nivel 1: Ejecutar la cadencia del calzado masculino/femenino presionando comandos sincrónicos coordinados con el repique de cajón.
Nivel 2: Desplegar el pañuelo virtual para esquivar los careos y aproximaciones de la pareja de baile dentro del Canvas.
39. El Enigma del Cerro Pilán
Nivel 1: Conducir un vehículo esquivando espejismos cinéticos generados artificialmente por las aberraciones físicas del relieve costero.
Nivel 2: Escapar de un laberinto con campos electromagnéticos variables donde los vectores del mapa se invierten periódicamente.
40. Mangaches contra Planchaos
Nivel 1: Defender los linderos históricos de la Mangachería posicionando estratégicamente defensores armados con elementos tradicionales.
Nivel 2: Sostener un combate dialéctico de cumananas (rimas improvisadas) seleccionando el contraargumento de mayor valor métrico.
41. El Vuelo del Cortarrama Peruano
Nivel 1: Controlar el vuelo horizontal estocástico de un ave cortarrama eludiendo líneas eléctricas de alta tensión en Talara.
Nivel 2: Localizar brotes tiernos de algarroba evadiendo la presencia de depredadores domésticos e invasivos.
42. El Oso de Anteojos en los Bosques de Neblina
Nivel 1: Rastrear bulbos de orquídeas raras trepando por riscos húmedos de la sierra de Ayabaca con visibilidad intermitente.
Nivel 2: Desactivar cepos y trampas de cazadores furtivos cortando los cables tensores correctos en la pantalla.
43. Sandboard en el Médano Blanco
Nivel 1: Descender vertiginosamente dunas empinadas de Sechura esquivando afloramientos de roca y plantas xerófitas.
Nivel 2: Ejecutar rotaciones angulares en el aire al salir eyectado de rampas naturales de arena compacta.
44. El Cruce del Río Piura en Época de "El Niño"
Nivel 1: Propulsar balsas improvisadas con cámaras de llanta transportando civiles a contracorriente de un caudal desbordado.
Nivel 2: Rescatar animales domésticos atrapados en montículos aislados lanzando un lazo con parábola física variable.
45. Ruta en Mototaxi a Colán
Nivel 1: Conducir un vehículo ligero de tres ruedas sorteando baches profundos, calaminas viales y ganado caprino suelto.
Nivel 2: Efectuar maniobras de aparcamiento de precisión geométrica en el estrecho malecón de madera sobre pilotes.
46. Cetáceos en El Ñuro
Nivel 1: Navegar embarcaciones turísticas rastreando las emisiones de vapor y estelas hidrodinámicas de ballenas jorobadas.
Nivel 2: Capturar registros fotográficos instantáneos ganando puntos según el centrado y la nitidez del encuadre en el salto del animal.
47. El Escape de la Serpiente Macanche
Nivel 1: Deslizar un ofidio nativo entre la arena del desierto buscando la cobertura térmica provista por arbustos de zapote.
Nivel 2: Evadir las pisadas y cascos de arrieros en tránsito ocultándose rápidamente en grietas del terreno arcilloso.

Nivel 2: Liberar los ejes enterrados en arena floja aplicando rampas de tracción mediante clics intensivos coordinados.
49. El Misterio de la Huaca Narihualá

50. Defensores del Algarrobal

3. Matriz de Evaluación Basada en Rúbricas (Escala de 20 Puntos)

La evaluación del proyecto de desarrollo se rige por cuatro criterios fundamentales, ponderados con un peso específico equivalente de 5 puntos cada uno, totalizando la nota vigesimal máxima (20):

Criterio de Evaluación Excelente (5 pts) Satisfactorio (3-4 pts) En Progreso (1-2 pts) Deficiente (0 pts)
1. Mecánica del Canvas y Lógica de 2 Niveles El bucle principal (Game Loop) es fluido a 60 FPS. El Nivel 1 y el Nivel 2 poseen mecánicas claramente diferenciadas, escalado de dificultad matemática coherente y colisiones de vectores sin fallos. El juego opera de forma interactiva pero presenta caídas aisladas en la tasa de refresco. La transición entre ambos niveles funciona, aunque las mecánicas carecen de un cambio sustancial en su lógica. Presenta fallos estructurales en la detección de colisiones. Solo es jugable el primer nivel o la transición de estados rompe el ciclo de ejecución de la aplicación web. No inicializa el lienzo Canvas, faltan los controladores de eventos principales (EventListener) o carece por completo de lógica lúdica.
2. Integración y Persistencia MySQL Conexión asíncrona perfecta usando la API Fetch nativa. Transfiere de manera segura variables validadas y registra de forma consistente el récord en MySQL mediante sentencias preparadas contra inyección SQL. Consigue conectarse con la base de datos y almacenar los récords, pero emplea arquitecturas síncronas obsoletas que congelan el hilo de ejecución del Canvas o carece de filtros de seguridad. El backend intenta comunicarse con la base de datos MySQL, pero la petición web devuelve errores HTTP constantes (ej. 500 o 404) debido a inconsistencias en el esquema de datos. Ausencia total de mecanismos de persistencia de datos. Los puntajes mueren al refrescar la ventana del navegador. No existe código de backend.

Identidad Cultural y Contexto Regional La narrativa, la estética de los recursos en Canvas y las mecánicas lúdicas reflejan fidedignamente la costumbre de Piura asignada, mostrando un valor educativo y etnográfico notable. El juego se asocia al tema de la región Piura seleccionado, pero los elementos gráficos o las mecánicas son genéricos y podrían sustituirse por cualquier otro contexto geográfico sin alterar el juego. La temática norteña es meramente superficial (ej. solo el título del juego). Las dinámicas internas contradicen o desvirtúan la realidad de la costumbre tradicional descrita. No guarda ninguna relación con las tradiciones, geografía o costumbres piuranas solicitadas en las especificaciones del proyecto.
4. Estructura de Código y Despliegue en GitHub Código limpio, modularizado y documentado. Repositorio en GitHub estructurado bajo buenas prácticas, con historial de confirmaciones (commits) transparente y archivo README técnico detallado. El código fuente está concentrado en un único bloque denso sin modularización, pero es legible. El repositorio existe en GitHub aunque cuenta con pocas confirmaciones o documentación escueta. Código confuso, sin comentarios y con variables mal nombradas. El repositorio de GitHub carece de estructura organizada o se cargó en un único bloque masivo al final. No se entregó el código fuente a través de la plataforma GitHub o los archivos compartidos están dañados e impiden la revisión del software.

4. Guía de Despliegue y Publicación en GitHub

Para alojar el proyecto de forma pública haciendo uso de las herramientas integradas de control de versiones, ejecute de forma ordenada la siguiente secuencia de comandos en la terminal de desarrollo:

  1. Inicializar el repositorio git local en el directorio raíz del videojuego:
    git init
  2. Vincular el entorno local con el repositorio remoto previamente creado en su cuenta de GitHub:
    git remote add origin https://github.com/SU_USUARIO/SU_REPOSITORIO.git
  3. Añadir todos los archivos del proyecto al área de preparación (Staging Area):
    git add .
  4. Confirmar los cambios capturando el estado inicial de la aplicación:
    git commit -m "Feat: Implementación del Game Loop en Canvas e integración de persistencia asíncrona"
  5. Desplazar las confirmaciones de código hacia la rama de producción remota:
    git push -u origin main
  6. Activación del Hosting Gratuito (GitHub Pages): Acceda a la interfaz web de su repositorio en GitHub, diríjase a Settings > Pages, seleccione la rama main como origen de despliegue y presione Save. En pocos minutos, el videojuego se ejecutará en vivo bajo una URL pública.
